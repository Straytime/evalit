# CHG-20260920-002：纠正 Trace metadata 关联语义

## 技术设计（先于测试与文档修正）

- 需求来源：用户重申 func_10 的关联对象是 Langfuse Trace 自身的 Metadata。
- 基线：Git a58d008 + 当前未提交的 techv_0.1 设计；不覆盖其他用户改动。
- 类型：技术设计纠错；不改变 PRD，不实现产品。
- 影响：技术设计第 11/12/25 节、ADR-005、TC-TRACE-08、追踪矩阵与文档测试。
- 正确契约：用 Agent 响应字段 A 的值，匹配 Trace metadata.B，按 traceId 去重，再获取整条 Trace；Observation 名称选择是获取 Trace 后的另一个步骤。
- 不变量：不把任意节点私有 metadata 当作 Trace metadata；不要求根节点保存关联字段；无需用户选择根/任意 Observation。
- 集成边界：Cloud API 的物理数据模型可以改变，但 adapter 必须验证 Trace metadata 语义等价。无法区分来源时显式报能力不兼容，不能静默换成节点私有字段。
- 回滚：本次仅文档，不产生数据迁移；不得回滚到与已明确需求冲突的建议。
