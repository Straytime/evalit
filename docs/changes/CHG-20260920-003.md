# CHG-20260920-003：零上下文独立评审与设计收敛

## 技术设计（先于测试和修订）

- 来源：用户要求零上下文 subagent 独立 review，并讨论、修订、复审直到一致。
- 基线：Git a58d008 + 未提交的 techv_0.1 / CHG-001、002；本次不改 PRD、原型或产品实现，不自动 commit/push。
- 审查者：independent_design_review，以 fork_turns=none 启动，自行读取仓库事实和官方接口资料；仅告知用户已明确的 TDD、Cloud、Trace Metadata 约束。
- 影响：主技术设计、测试策略、TDD 工作流、ADR、追踪矩阵、文档测试及本记录；README 更新评审入口。
- 回滚：纯设计修订，无运行数据迁移；不得恢复已确认的矛盾。既有用户变更保留。

### 本轮增量契约与验收

1. **可选 body 输入**：区分可选变量未绑定与绑定后值缺失。前者省略对应属性，后者仍按 PRD 为 not_evaluable；Header/Prompt/评估器变量必须绑定。必填性按规范化 Schema 和已配置的对象展开结构判断，完整 body 构造后再次校验。
2. **回执无循环**：传输、解析确认、Trace 验证使用有向依赖链及各自哈希。生成解析规则/响应 Schema 不使其来源试调用失效；请求变更须新调用，说明变更可重用完整事件但须重新生成、确认。保存不偷偷调用外部服务。
3. **阶段 CAS 独立**：stage_attempts 持有每个 target/Trace/evaluator 独立的 stage_revision、core_epoch、终态。并发评估器不能竞争 case 级 token；阶段终态、镜像结果、计数和事件同一事务。
4. **进程生命周期**：Main broker 是 utilityProcess 唯一创建/终止者，关联 coreEpoch/taskId/child handle；Core 不调用 Main-only API。超时硬终止不依赖 SIGTERM，退出确认前不释放执行名额、不重建数据库写者。
5. **产出持久化**：临时文件与最终路径同卷；文件持久化、原子 rename、受影响目录同步均先于 DB 引用提交。恢复核验文件存在性与哈希，失败不伪装历史产出完整。平台屏障能力需真实验证，不夸大断电保证。
6. **有限均值**：不能直接用 Number 累加和再除 n。选择 binary64 精确整数聚合与最终 nearest-even 舍入，覆盖巨大同号、异号抵消、次正规数；不因中间溢出将合法指标输出为 Infinity/null。
7. **平台相关 TDD**：Linux 协调 gate，RED/GREEN 在同一目标平台和锁定工具链重放；macOS 原生测试不由 Linux skip/mock 代替。固定 required check 汇总可信平台证据，缺失不放行。
8. **编译期隔离**：TS 编译使用纯内存 CompilerHost、固定虚拟源码和打包白名单 lib；禁止 triple-slash 外部引用、自动 types 与模块解析，不调用默认文件系统 host。编译与执行分别以 canary 验证零越权读取/网络。

外部前提继续单列：真实 Cloud 的 Trace Metadata 等价读取、时间窗/分页/可见性以及签名发布条件。文档一致不等于真实集成或产品功能已经验证。

### 第二轮增量设计（先于测试/修订）

- R9：独立阶段占位修订后，开启 Trace 的 target 缺输入/失败时，queued Trace 缺少终止分支；不能在 case/run 结束后留下未决权威阶段。
- 契约：target failed/not_evaluable 的同一事务，将尚未执行的 Trace 与 evaluator 都置 not_evaluable / TARGET_UNAVAILABLE；恢复补齐遗留占位且保留已提交终态。target success、Trace queued 或 dispatched 时，恢复均终止 Trace failed / EXECUTION_INTERRUPTED，再按各评估器依赖收敛。
- 验收：TC-RUN-07，运行与恢复后所有应执行阶段均终态、零额外 Trace/Agent/评估器调用；case/run 仍按 PRD 聚合，不新增业务状态。
- RED 实际：同一文档测试命令退出码 1，14 pass / 1 fail，失败断言“正常失败分支必须终止 Trace 占位”；随后修订主设计正常执行/恢复分支，增加 TC-RUN-07 并更新矩阵。
- GREEN 实际：同一命令退出码 0，15/15 通过。
- R10：第 17 节固定 IPC DTO 未同步回执链，首次 SSE 不能立即返回 inferredSchema；Trace 第二次调用必须把新链交给前端。
- R10 契约：testCall 用 blocking/streaming 辨别结果；generateParser/confirmParser 显式区分生成与确认；产生回执的验证步骤返回 Core 持有的最新 validationReceiptId，testTrace 返回含新 Transport/Parse/Trace 的组合 ID，saveAgent 只接受当前组合 ID 并后端核验。旧组合 ID 失效，不混搭；保存零 Agent 调用，测试覆盖仅两次请求完成带 Trace 的创建。
- R10 RED 实际：同一命令退出码 1，15 pass / 1 fail，断言“SSE 传输阶段不能无条件推断 Schema”；后同步主设计第 7/17 节、TC-IPC-03 和矩阵。
- R10 GREEN 实际：同一命令退出码 0，16/16 通过；git diff --check 通过。第二轮累计新增 TC-RUN-07、TC-IPC-03，产品验收规格共 90 组。
